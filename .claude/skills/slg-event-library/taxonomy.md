# 分类体系

## 维度一：活动类型（9 类）

| 类型 | 典型代表 | 核心机制 | P2 对标 |
|---|---|---|---|
| **抽奖 gacha** | Whiteout Lucky Wheel / CoD Lucky Flip | 转盘/翻牌/保底 | 联动礼包 / 行军特效礼包 |
| **累充/累付** | 所有 SLG 通用 | 累计充值阶梯奖励 | 2011 累充（已有） |
| **Battle Pass** | 绝大多数 SLG | 进度条 + 付费解锁高级道 | 2019 BP（已有） |
| **集卡/碎片** | ROK Lucky Stall / Evony Compose | 收集 → 合成/兑换 | 2013 联动礼包碎片 |
| **挖矿/探险** | Whiteout Treasure Hunter / Last War Hidden Treasure | 地图挖掘，累积奖励 | 2020 挖孔（已有） |
| **限时商店** | ROK Lucky Stall / Last War Easter Shop | 刷新式折扣购买 | 1168 商店（已有） |
| **PVP/竞速** | 几乎所有 SLG | 排行榜 + 档位奖 | 2121 排行（已有） |
| **IP 联动** | Last War × 火影 / SoS × 生化 | 专属皮肤+限定角色 | 2013 联动（已有） |
| **节日包装** | 全节日主题 | 上述类型 × 节日皮肤 | P2 所有节日（已有） |
