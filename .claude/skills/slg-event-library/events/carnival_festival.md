# Carnival / Festival 节日嵌套综合活动

## 机制总览

```
一个节日主题 ↓ 多玩法并行：
  ├── 每日登录奖励
  ├── 节日任务链（累积代币）
  ├── 限时商店（代币兑换）
  ├── 抽奖转盘（代币入场）
  └── 限定礼包 + IP 联动
```

## 设计要点

1. **一个代币穿起所有活动** — 玩家在任务/登录得代币，能在商店 + 抽奖 + 兑换三路消耗
2. **节日视觉全覆盖** — 主城、地图、UI 全部换皮
3. **IP 联动锦上添花** — 节日期叠加 IP 联动，付费动力拉满

## P2 落地映射

- 这就是 P2 节日活动的标准形态，对应表组合：
  - **2121**（任务）+ **2011**（累充）+ **1168**（商店）+ **1111**（抽奖）+ **2013**（联动）+ **1512/2112**（装饰/特效）
- **当前 P2 做得好的**：节日视觉 + 联动礼包
- **可加强的**：统一代币体系（目前各活动代币互相隔离，不能跨活动消耗）
