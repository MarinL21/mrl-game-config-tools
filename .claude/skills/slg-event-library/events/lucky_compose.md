# Lucky Compose / Lucky Bag 合成打卡型 gacha

## 机制总览

```
每日登录 → 抽奖一次（免费/钻石）→ 累计 N 天 → 金袋保底（必出顶级）
         ↓
         同时走合成线：碎片收集 → 合成 → 开盲盒
```

## 设计要点

1. **日活驱动** — 每日打卡才能抽奖，11 天保底让"坚持登录"成为强需求
2. **抽奖=日常不是爆发** — 不像转盘靠大金额一次性抽，靠持续投入
3. **合成+抽奖双轨** — 碎片合成给非酋兜底

## P2 落地映射

- 对应组合：**2121**（每日任务）+ **1111**（抽奖）+ **2013**（碎片合成）+ **1168**（打卡商店）
- **强推**：节日活动挂 N 天打卡保底，奖池最后一天爆节日皮肤
- 适合长节日（周年庆 14 天、春节 21 天）
