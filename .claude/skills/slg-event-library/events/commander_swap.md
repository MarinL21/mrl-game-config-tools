# Commander Swap 升级置换型 gacha

## 机制总览

```
玩家选一个"已升满的旧指挥官" → 经验/技能/装备 一键迁移 → 新指挥官从 0 升到满级
                                                      ↑
                                          老 R 玩家的"沉没成本"被复用
```

## 代表案例

| 游戏 | 活动名 | 视频 |
|---|---|---|
| Rise of Kingdoms | **Commander Swap** | [F2P 流程](https://www.youtube.com/watch?v=Zs4-vLCoe7U) / [会回归吗](https://www.youtube.com/watch?v=qRDniXZIi08) |

## 设计要点

1. **让沉没成本再次产生付费动力** — 老玩家升满的角色"过气"后，不是被淘汰而是被复用
2. **降低新角色入门门槛** — 抽到新角色不用重新养成
3. **稀缺事件** — 不是常驻，半年/一年开一次，强化稀缺感

## P2 落地映射

- 没有完全对应玩法，但可启发：
  - **节日皮肤升级置换** — 玩家可以把旧节日主城皮肤的等级/特效"转移"给新节日皮肤
  - 对应表：**1512**（装饰物）+ **2013**（节日联动）
- 适合周年庆、跨年节点
