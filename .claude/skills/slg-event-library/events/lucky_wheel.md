# Lucky Wheel 转盘类 gacha

## 机制总览

```
[钻石/代币] → [转盘点击] → [随机出货] → [未中继续转] → [保底触发]
              ↑ 每期换 featured 奖品
```

## 设计要点

1. **保底要透明公示** — F2P 能算出期望值
2. **Featured 奖品换期** — 保持新鲜感
3. **多档位奖池** — 通用奖 + 节日专属 + 顶级毕业奖

## P2 落地映射

- 对应表：**1111**（抽奖池）+ **2013**（联动礼包源头）
- 节日期间挂在 SoP / 周年庆期间
- 奖池分层：节日表情（低端）+ 节日特效（中端）+ 节日主城皮肤（高端）
