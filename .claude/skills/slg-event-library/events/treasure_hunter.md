# Treasure Hunter 累积升级 gacha

## 机制总览

```
每次抽奖 → 进度 +1 → 里程碑 1 奖 → 里程碑 2 奖 → ... → 满进度顶级大奖
           (即使没抽到也不亏，保底由阶梯兜底)
```

## 设计要点

1. **双层保障** — 即使抽奖没出货，累积进度也能拿阶梯奖，**降低挫败感**
2. **顶级大奖要值回票价** — 满进度（通常 $500 级别）要能换来毕业级道具
3. **进度条可视化** — 玩家能清楚看到"还差几抽"

## P2 落地映射

- 对应表：**2011**（累充阶梯思想）+ **1111**（抽奖次数）+ **1168**（阶梯奖）
- **强推**：节日期间挂 Treasure Hunter，抽奖用"节日代币"，满进度爆**节日限定主城皮肤**
- 阶梯档位建议：$0 → $30 → $98 → $298 → $500（大节日）/ $300（小节日）
