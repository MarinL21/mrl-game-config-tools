# Lucky Cards 地图翻牌型 gacha

## 机制总览

```
大地图铺满卡牌 → 玩家点击翻开 → 数字/图案组合 → 最大组合数换钻石/道具
                                  ↑ 带博弈策略，不是纯随机
```

## 设计要点

1. **空间型抽奖** — 抽奖发生在地图/棋盘上，增加沉浸感
2. **组合博弈** — 不是点一下出货，需要玩家思考怎么组合
3. **超额大奖** — 99999 宝石的极端奖池吸引眼球（即使概率极低）

## P2 落地映射

- 没有完全对应 P2 玩法，但可考虑做**节日主题地图翻牌**：
  - 春节：红包墙翻牌
  - 万圣：南瓜墙翻牌
  - 情人节：玫瑰墙翻牌
- 结合 **2135**（地图交互）+ **1111**（抽奖产出）
