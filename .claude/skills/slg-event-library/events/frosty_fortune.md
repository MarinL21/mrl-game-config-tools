# Frosty Fortune 三合一抽奖面板

## 机制总览

```
同一个面板 3 个 Tab：
┌───────────────┬──────────────────┬───────────────┐
│ Treasure Drill │  Frosty Fortune │ Emporium Enigma│
│ (累积抽奖)     │  (主抽奖池)       │  (兑换商店)    │
│ → 产 D 币      │  → 产 F 币        │  → 用 D+F 换  │
└───────────────┴──────────────────┴───────────────┘
                         ↓
                  最终奖品：**永久城市皮肤 / 行军皮肤**
```

## 设计要点

1. **面板而非事件** — 三个 Tab 共用一个入口，降低玩家切换成本
2. **货币互通** — D 币 + F 币双货币，在 Emporium 可以混着花
3. **永久奖品** — 城市皮肤/行军皮肤永久入库，不是消耗品，付费动力拉满
4. **多付费段位** — 轻氪玩 Treasure Drill，中氪玩 Frosty Fortune，大氪打 Emporium 毕业

## P2 落地映射

- 对应组合：**1111**（抽奖）+ **2013**（联动礼包兑换币）+ **1168**（商店）+ **1512**（永久装饰）
- **最值得抄**：节日期把 3 个独立活动（抽奖 / 集卡 / 限时商店）合并到**一个 Tab 面板**，大幅提升用户留存
