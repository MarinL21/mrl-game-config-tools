## 设计内核

1. **保底必须透明** — Lucky Wheel 有软保底，F2P 能算 EV
2. **活动嵌套** — 4 类活动同时在线，分别吸引不同付费段位
3. **永久奖品是主诱饵** — 城市/行军皮肤永久入库，不是消耗品
4. **赛季绑定** — SoP 赛季到来才开 Lucky Wheel，强化紧迫感
