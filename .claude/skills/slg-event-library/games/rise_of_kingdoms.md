## 设计内核

1. **折扣≠抽奖** — Lucky Stall 是"伪随机折扣"，本质是刷新式商店，付费门槛更低
2. **沉没成本再利用** — Commander Swap 让"旧角色养成资源"成为新付费动力
3. **周年庆才开大抽** — Lucky Dice 是稀缺事件，保持仪式感

## P2 对标

- Commander Swap → 没有完全对应的 P2 玩法，可考虑做"节日皮肤升级置换"
- Lucky Dice → 周年庆专属抽奖
