## 关键规则

### gacha 道具每节日必问用户（**禁默认**）

T1-T10 主奖励槽位的 gacha 道具 ID 必须每次主动问用户，不能凭节日名 grep（"拓荒节通用 GACHA 11112164" 看似对应但用户实际要 "11112649 周年弹珠"——投放策略层）。

T11（每日累充1500）的奖励是另一套（节日自选宝箱+加速类），跟主奖励槽无关，不在此问范围。

### 通用 vs 节日专属槽位（每档 reward 数组）

**节日专属（每节日换 1 处）**：
- T1.slot1 第二槽 / T2-T10.slot1: gacha 道具×N（拓荒节 = `11112649`）
- T11.slot1: 本节日自选宝箱（拓荒节=`111110325`，春节=`11119941` 等）

**通用复用（不换）**：
- T2 第二槽 `11112163`（2024拓荒节犀牛染色自选）— 历史遗留跨节日
- T5 第一槽 `11112280`（感恩节机甲自选假道具）— 跨节日
- T11 第二/三槽 `11111152` / `11111002` 通用加速

### 数量递增曲线（T1→T10）

参考拓荒节2026 / 春节2026 模板：
- T1 (1250): 5 / T2 (3750): 12 / T3 (12500): 25 / T4 (25000): 50
- T5 (50000): 200 / T6 (100000): 200 / T7 (175000): 450 / T8 (300000): 450
- T9 (400000): 500 / T10 (500000): 550
- T11 (1500-每日): 节日宝箱×3 + 加速×5×2

## 与 cityeffect-recharge skill 的关系

机甲累充 **跟主城特效累充独立**，但通常同节日同时上线：
- 2112 实例 ID 通常分配在主城特效累充 ID 之后（拓荒节：21127892/893/894 主城特效 + 21127891 机甲）
- 共用同节日 1168 access_group + 2111 calendar 占位符段
- 机甲累充**不进 1168 access_group args 列表**（不是核心付费跳转目标）
