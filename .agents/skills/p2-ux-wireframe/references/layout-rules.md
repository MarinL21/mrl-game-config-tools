## 一、两个画布，别混

| | 尺寸 | 用途 |
|---|---|---|
| **单屏** | **1920×1080**，硬尺寸 | 一个界面 = 一个 Frame。出图后必须校验真实像素 |
| **画板** | 自由（真稿 6264×7438） | 承载多屏 + 标注 + 流程箭头。不要求整数倍 |

`p2-game-ux` 写的 `1376×768` 与真稿的 `1920×1080` 冲突。已确认以 **1920×1080** 为准，
1376×768 归为 AI 出图那条线的交付尺寸。

## 二、画板板式 —— 两套并存，按用途选

### 甲式「流程板」（分层累充）
黑底 `#0D0D0D` + ▍青竖条大标题 + `（1）（2）` 中文括号章节 + **青色**标注与引线。
用途：讲**从头到尾怎么走**。

### 乙式「改动标注板」（本体 gacha / 掉落转付费）
深蓝灰底 + **顶部整条渐变标题条**（左上黄字写活动名）。
每张界面**外包橙色描边框**，框左上角贴一个**橙色小标签**写界面名
（主活动界面 / 弹碰奖励预览 / 不同档位示意01 / 活动概率展示 / 不同状态展示 / 兑换商店）。
标注一律**红色**：红字 + 红箭头 + **红色矩形框圈出改动点**。
用途：讲**这一版改了什么、哪个元素要有什么反馈**
（「可点击时有闪烁提示」「不可点击时置灰」「碰撞时有飘字」「数字变化时反馈」
「切换档位时上方按钮颜色变化，下方道具数字有放大、发光反馈」）。

选哪套：新玩法从零讲流程 → 甲式；在现有界面上提改动与反馈 → 乙式。

### 甲式细则

```
黑底 #0D0D0D
├ ▍<标题>                    青色小竖条 44×76 + 白色 76px 900 字重
├ （1）策划需求               50px 白字，中文全角括号编号
│    └ 竞品参考截图 1 张
└ （2）交互流程
     ├ 「主界面信息：」+ 一张单屏，左右两侧拉青色引线出标注
     ├ 界面矩阵：每格 = 白色 34px 标题 + 一张单屏，格间青色细箭头
     └ 状态序列：浅灰 #2E2E2E 圆角块，蓝色粗箭头串 1→2→3
```

**标注只用一个色系**：标题白 `#FFFFFF` 30px 粗体，说明青 `#3ED8E0` 28px。
多条说明用 `1. 2.` 编号。引线 3px 青线 + 三角箭头。
⛔ 不要像浅色线框那样上红/橙/蓝三色——真稿全篇只有青色一色。

## 三、单屏骨架：先分类型，再排版

**左导航条 369 是所有活动页共有的**。它右边那 1551px 怎么分，取决于活动类型 —— 两套形态：

### A 型　任务 / 累充类　→　三段式
证据：分层累充。中央放场景与主体，右侧挂 **739×898** 信息面板。

| 段 | 宽 | 装什么 |
|---|---|---|
| 左导航条 | 369 | 返回 + 分组 + 页签 |
| 中央 | ~811 | 满屏场景 + 玩法主体 |
| 右信息面板 | 739 | 任务列表 / 阶段奖励 / 按钮 |

### B 型　小游戏 / 玩法盘类　→　盘面占满 + 四角挂件
证据：**幸运弹弹弹**（8月周年庆本体 gacha）、挖孔。
**没有右侧大面板**，玩法盘从导航条右边一直铺到屏幕右缘；所有辅助功能挂在盘的四周与四角。

| 位置 | 挂什么 | 实测 |
|---|---|---|
| 盘面上方 | 发射口 / 操作入口一排 | 5 个发射口 + 黄色提示条「点击任意洞口发射弹珠」 |
| 盘面**左上或右上（外侧）** | 排行榜卡片 | 大奖缩略图 ×2 + 「全服 TIPS」+「本服 34th」+ 奖杯圆按钮 |
| 盘面**左侧或右侧（外侧）** | **垂直**积分进度条 | 绿色填充 + 刻度 ×10/×30/×50/×80/×110 + 奖励格竖排 + 底部当前值徽章 |
| 盘面左上角外侧 | 档位 / 倍数选择器 | 橙色按钮显当前档 + 点开竖向下拉列表，当前档橙色高亮 |
| 屏幕左下角 | 规则 ⓘ | 白色 i，压在场景上 |
| 屏幕左下 / 右下角 | 兑换商店等二级入口 | 图标 + 文字，不做成方块图标列 |
| 屏幕右下角 | 倒计时 | 「进行中 06天11时」白描边字直接压场景 |
| 屏幕右上角 | 资产条 | 道具图标 + 数量 + 绿色【+】 |

⛔ **B 型不要自造「右侧信息面板」**，也不要把排行榜/商店/成就做成竖排方块图标列 ——
那是我 v0.1 的臆造，真稿里没有。

## 四、左导航条（369×1080）—— 骨架，不许省

自上而下固定顺序，尺寸为实测值：

| 元件 | 尺寸 | 位置 | 说明 |
|---|---|---|---|
| 底板 | 358×1080 | (0,0) | `#1A1A1A` |
| 返回按钮 | 189×113 | (11,17) | 灰紫底 `#2E2E2E` + 白粗描边 `<` 49×69 |
| 分组标题条 | 345×56 | 居中 | 橙字 `#E8A020`，如「热门活动 / 普通活动 / 赛事」 |
| 一级页签·选中 | **368×152** | 左对齐 0 | 黄 `#FFC600` + **右侧尖角外凸 10px**（比底板 358 宽） |
| 一级页签·未选中 | 纯文字 | 居中 | 52px 灰白 `#C8CDD4`，**不给底板** |
| 二级页签组底 | 318×308 | 挂在选中项下方 | 深色圆角容器 |
| 二级页签·选中 | 287×108 | 组内 | 青蓝 `#00CFEE` + 黑粗描边 |
| 红点 | — | 页签右上 | 只用于「有可操作收益」 |

**这是母版，不许换皮**：不许改成蓝色主题、不许改成圆角卡片组、不许挪到顶部、
不许换掉黄色选中态的尖角造型。允许变的只有页签文案 / 数量 / 红点 / 选中的是哪一项。

## 五、右侧信息面板

| 元件 | 尺寸 | 说明 |
|---|---|---|
| 面板底 | **739×898** | `#161013` |
| 顶部标题标签 | 298×127 | **悬在面板上边缘之外**，斜切标签造型 |
| 列表行 | 704×192 | 斑马交替底，行内四段见下 |

单行内部四段（左→右）：
1. 任务标题，白字黑描边，**其中的数字用绿色** `#3EEE00` 单独染色
2. 右上进度 `(6/6)`，数字用青色 `#00CFEE`
3. 奖励格 ×3，格底 94×94（`UiItemsBg03` 青 / `UiItemsBg05` 黄）+ 图标 68×68 + 右下 `x5`
4. 按钮，三态：绿 199×75「领取」/ 蓝 208×78「前往」/ 无按钮纯绿字「已完成」

## 六、玩法盘（B 型专用）

- **发射/操作口在盘面顶部一排**，不是底部一个大按钮。上方压一条黄色提示条讲怎么操作。
- **操作中 = 操作口整排置灰**（幸运弹弹弹弹射中，发射口从橙变蓝灰且三角消失）。
- **落点槽 = 道具图标 + ×数量 + 品质色圆盘**，中央最高两侧递减（×100/×500/×1500/**×3000**/×1500/×500/×100）。
  ⛔ 不要用纯文字「×1 ×2 ×3」，那不是 P2 的做法。
- **命中反馈三件套**：飘字（`+200` 绿色带描边）+ 目标物发光/描边 + 弹珠拖尾。
- 盘面底部有**回收导轨**，弹珠滚落收口。

## 六之二、中央玩法区（A 型）

- **满屏场景做底**，玩法主体压在场景上。⛔ 不是纯色面板铺满——这是我第一版最大的错。
- 玩法主体（楼层 / 建筑 / 装置）上挂**铭牌**：气泡 223×224 + 1511 图标 76×76 + 名称 + 锁 icon 43×54
- **选中态两件套**：黄色四角选框 + 静态发光描边（真稿标注原文：「1.楼层铭牌处有选框
  2.被选中楼层有静态发光描边效果（强调选中状态）」）
- 系统/活动名：78px 900 字重 + 7px 深色描边，压在场景左上、导航条右侧

## 七、文字规范

P2 最强的视觉签名是**粗黑体 + 粗深色描边**（`-webkit-text-stroke` + `paint-order: stroke fill`）。

| 用途 | 字号 | 描边 |
|---|---|---|
| 活动/系统名 | 78 | 7px |
| 一级页签 | 52–62 | 4px |
| 数值（星数/属性值） | 60 | 4px |
| 行标题 / 正文 | 30–38 | 3px |
| 分组标题条 | 30 | 0（橙色，不描边） |

**数字必须单独染色**：绿=已达成/正向增量，青=进度分数，黄=当前值。

## 八、四骨架的适用边界

`p2-game-ux` 第 23 条要求活动页保留四骨架（左导航 / 左上名+描述 / 右上 CD 资产条 /
右下倒计时），但**实测的分层累充真稿只有左导航**，其余三项都没画。

结论：
- **左侧导航条是硬骨架**，任何活动页都不许省
- 其余三项按页面性质定；**常驻系统页可豁免，但必须在图上写出豁免声明**，不许默默省掉
