# P2 节日道具文案风格基准

## 这个 skill 解决什么问题

运营策划每月出新节日时，要给**主城皮肤/机甲/行军特效/头像框/表情/铭牌/装饰物/活动名**等一批道具写"名称 + 描述"。
过去的问题：每个节日风格不一致，头像框英文有时创意有时直译，时长后缀 `_24h` / `_1d` 混用，节日关键词散乱。
本 skill 把 2023~2026 近 3 年真实样本抽出来，**按 10 个道具大类固化模板**，保证新文案与历史保持同一风格。

配套工具：
- 本 skill 只管 **中文原文 + 英文主译**的风格
- 18 语言扩散走 `p2-translation-automatic`（它会查规范库、翻译记忆再做 AI 翻译）
- 写入 Sheet 走 `p2-translation-automatic` 的暂存区流程

## 风格指南正本

**唯一正本**：`/Users/marinl/游戏运营策划工具/P2道具翻译风格指南.md`

## 标准执行流程

### Step 0：读风格指南（不可跳过）

```bash
# 必做
cat "/Users/marinl/游戏运营策划工具/P2道具翻译风格指南.md"
```

读完后在对话里告诉用户：**"我已经按 xxxx 年 xx 节日的 风格基准来写"**，不要默默开写。

### Step 1：识别道具类型

用户给需求时，先判断落在 10 个大类的哪一类。判断依据：

| 关键词 | 道具类型 | 风格指南对应小节 |
|--------|---------|----------------|
| 主城皮肤 / 城堡 / city_skin / city_suit | 主城皮肤 | 3.1 |
| 机甲皮肤 / hero_skin / 大象/猎豹/战龟/毒蝎 + "皮肤" | 机甲皮肤 | 3.2 |
| 机甲染色 / 涂装 / dye | 机甲染色（**双套文案**） | 3.3 |
| 行军特效 / march_effect / 高级行军/低级行军 | 行军特效 | 3.4 |
| 行军表情 / map_emoji / emoji | 行军表情 | 3.5 |
| 头像框 / avatar_frame | 头像框 | 3.6（注意新旧两期） |
| 铭牌 / 聊天框 / chat_skin / nameplate | 铭牌聊天框 | 3.7 |
| 节日装饰 / city_decoration / 装饰物 LV1/LV2/LV3 | 装饰物 | 3.8 |
| Bingo / 大富翁 / 挖孔小游戏 / 集卡 活动名 | 活动名称 | 3.9 |
| 活动道具 / 凭证 / 骰子 / 礼包名 | 活动道具 | 3.10 |

**判断不准时**，直接问用户是哪类——不要默默选。

### Step 2：按该大类模板产出中文

固定动作：
1. 到风格指南对应小节，抄 **字数约束**、**结构模板**、**3~5 条真实样本**
2. 去"节日主题关键词表（第五节）"取本次节日的关键词
3. 产出中文文案，**字数、结构、关键词全部对齐**

**死守的几条**（详见指南第七节反面清单）：
- 名称 **2~4 字**（例外仅限历史遗留长名）
- 描述 **12~25 字**，中文用全角标点
- 机甲染色必须 **双套**（染色名+展示描述 / 道具名+道具描述），道具描述固定句式 `使用后可激活<机甲>机甲"<染色>"涂装。`
- 头像框描述 **不写获取途径**（那是 `get_from` key 的事）
- 表情名称 **不拼节日**（"复活节-比耶"❌，"比耶"✅，节日靠 constant key 后缀区分）

### Step 3：产出英文主译（名称 + 描述）

对照风格指南对应小节的英文样本来写：
- **名称**：Title Case，1~3 词优先；头像框可适当创意/音韵/文化引用
- **描述**：抓意象重写成自然英文，允许 `!` 强调；**不要逐字直译**
- **时长变体**：`(N-Day)` 或 `(Nd)` 与中文 `（N天）` 配对，同系列沿用已有后缀

### Step 4：术语核查（进入 p2-translation-automatic 流程前）

对名称 / 描述里出现的**名词性术语**（机甲名、活动名、道具名、节日关键词），依次：

```bash
cd "/Users/marinl/游戏运营策划工具"
python glossary_lookup.py "猎豹" "警戒者" "挖矿" ...   # 先查规范库
python search_terms.py "<未命中的>" ...                  # 再查 ITEM 表在线
```

命中的必须直接用——这保证同一术语跨节日永远一致。

### Step 5：交接给 p2-translation-automatic

把 Step 3 的 **cn + en** 交给 `p2-translation-automatic` skill 做 18 语言扩散 + 写入 Sheet 暂存区。
不要自己在本 skill 里完成 18 语言翻译，也不要直接写回 Sheet。

## 反面清单（别踩）

- ❌ 名称写成完整一句话 → ✅ 2~4 字
- ❌ 英文描述逐字直译中文 → ✅ 抓意象重写
- ❌ 描述堆功能参数（+X%、持续 Y 秒） → ✅ 功能信息放 `get_from` / `desc_N`，本名描述只写氛围
- ❌ 头像框英文 = 拼音/直白名词 → ✅ 意译/音韵/文化引用（Les Miserables / Thorn In My Sidearm）
- ❌ 机甲染色只给一套文案 → ✅ 染色名+展示 / 道具名+道具描述
- ❌ 时长后缀 `_1d` / `_24h` 混用 → ✅ 同系列沿用已有后缀
- ❌ 中文描述用半角 `,.!?` → ✅ 全角 `，。！？`
- ❌ 表情名称拼节日（"复活节-比耶"）→ ✅ 纯情绪词"比耶"
- ❌ 节日关键词在本节日内混乱（一会儿 tech 一会儿 sci）→ ✅ 一个节日一套主词
