# 学习模式分类

## 1. 修正型学习

用户纠正 AI 的错误。

**识别信号**：
- "不对"、"错了"、"应该是"
- 用户直接修改输出
- "这样不行"

**提取重点**：
- 错误的做法是什么
- 正确的做法是什么
- 为什么会犯这个错误

**经验模板**：
```markdown
## [避免xxx错误]

### 场景
[什么情况下容易犯这个错误]

### 错误做法
[原来的错误做法]

### 正确做法
[应该怎么做]

### 原因
[为什么这样是对的]
```

## 2. 偏好型学习

用户表达个人/团队偏好。

**识别信号**：
- "我喜欢"、"我习惯"
- "我们团队"、"我们公司"
- "风格"、"格式"

**提取重点**：
- 偏好的具体内容
- 适用范围（个人/团队/项目）
- 是硬性要求还是可选建议

**经验模板**：
```markdown
## [用户偏好：xxx]

### 偏好内容
[具体偏好是什么]

### 适用范围
[个人 / 团队 / 项目]

### 优先级
[必须遵守 / 尽量遵守 / 可选]
```

## 3. 知识型学习

用户分享领域知识。

**识别信号**：
- "其实"、"实际上"
- "原理是"、"因为"
- 技术解释、背景知识

**提取重点**：
- 核心知识点
- 与现有认知的差异
- 实际应用场景

**经验模板**：
```markdown
## [知识点：xxx]

### 核心内容
[知识点的核心]

### 常见误区
[容易理解错的地方]

### 应用场景
[什么时候用到这个知识]
```

## 4. 流程型学习

用户介绍工作流程。

**识别信号**：
- "流程是"、"步骤"
- "先...再...然后"
- "规范"、"标准"

**提取重点**：
- 完整的步骤序列
- 每步的要点
- 例外情况处理

**经验模板**：
```markdown
## [流程：xxx]

### 步骤
1. [步骤1]
2. [步骤2]
3. ...

### 注意事项
[每步的关键点]

### 例外处理
[特殊情况怎么办]
```

## 5. 反馈型学习

用户对输出质量的反馈。

**识别信号**：
- "太长了"、"太短了"
- "太复杂"、"不够详细"
- "这个好"、"这样不好"

**提取重点**：
- 反馈的具体维度
- 用户期望的标准
- 调整方向

**经验模板**：
```markdown
## [输出调整：xxx]

### 反馈内容
[用户说了什么]

### 调整方向
[应该怎么调整]

### 适用场景
[这个调整适用于什么场景]
```
