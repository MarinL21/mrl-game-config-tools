# P2/AOA 数值制作与养成线深度

## 定位

两大核心职能：

1. **活动数值制作**：从策划案出发，完成道具选型→数量计算→ROI校验→分层设计→配置输出。不替代策划案撰写（`p2_document`）和数据分析（`slg-activity-data`），是两者之间的桥梁。

## 核心原则

### 1. 先大纲后落数

不要一上来就填表。流程是：**拉数据 → 定大纲（档位/门槛/ROI目标）→ 用户确认 → 出单个样例确认规则 → 批量展开 → Excel**。大纲没对齐就填表 = 必返工。多日活动先出一天样例对齐，单日活动直接从大纲进入选道具。

### 2. 数据驱动定门槛

付费门槛不能拍脑袋，必须基于实际玩家付费分布数据。用 SQL 或 gamedata 拉取目标期间的日均消费分位数（中位数/P75/P90/P95），再决定每档对应哪个付费人群。

### 3. 逐档校验 ROI

每档单独算 ROI = 本档奖励价值 / 付费增量（本档累计付费 - 上档累计付费）。不能只看总 ROI。Excel 必须有「付费增量」「档位ROI」「ROI达标」三列。

### 4. 递进不倒退

这是最容易犯的错，三条铁律：

**稀缺性递进**：高档位道具品质 ≥ 低档位。蓝色→紫色→橙色，绝不能反过来。

**数量递进**：同类道具在高档位的数量 ≥ 低档位。

**面值递进**：同类加速/行动力/经验等，高档位的面值 ≥ 低档位。15分钟→60分钟→2小时→8小时；行动力50→100→500→1000；英雄经验10000→50000。"大于等于"即可，相同面值可以连续出现多档，但绝不能出现高档给低面值。

**档内排序**：同一档位内的道具按单价从高到低排列，高价值/高稀缺道具排前面。例如行动力1000点排在500点前面，橙色碎片排在紫色前面。

**跨档位置一致**：同类道具在不同档位中尽量保持相同的位置顺序。例如主题道具始终排第一组，碎片排第二组，资源填充排最后。让玩家跨档对比时一目了然。

**不够就跳过，不要降级**：当某档预算不够放当前等级的主题道具时，不放主题道具，改用非主题填充（资源/电池），而不是放一个更低等级的主题道具。
- ✓ 档3-5放60分钟加速 → 档6不放加速（用电池填充）→ 档7放2小时加速
- ✗ 档3-5放60分钟加速 → 档6放15分钟加速（倒退）→ 档7放2小时加速

### 5. 投放线连贯

活动中存在多条并行的投放线（如碎片线、主题道具线、资源线），每条线要保持自身的连贯性：

**主投放线不能中断**：如果档4-5都投放了万能碎片，档6（核心转化档）也必须延续万能碎片，不能突然换成低价值的其他道具（如升星材料）。核心转化档的吸引力 = 延续主线 + 独占奖励（如钥匙）。

**主题道具线差异化**：多日活动中，若每天有不同任务主题，可按主题配不同类型的主线道具形成闭环；单日活动或无主题差异的活动则统一主线道具即可。

### 6. SCHEMA 先行

做数值第一步就确认活动所在 SCHEMA，只能选该 SCHEMA 及之前已开放的道具。不查 SCHEMA 就选道具 = 必出错。

## 制作流程

### Step 1：确认框架

从策划案中提取，不清楚的主动询问：

| 项 | 说明 |
|----|------|
| 活动类型 | 礼包/周卡/商店/排行/积分消耗/混合 |
| 活动所在 SCHEMA | 决定可用道具范围 |
| 目标 ROI | 逐档目标，如 15-20% |
| 免费/付费分界 | 免费玩家能拿到几档 |
| 付费驱动方式 | 直购/积分换算/消耗兑换 |
| 是否多日/多主题 | 决定是否需要按日差异化奖励 |

### Step 2：拉数据定基线

用 SQL 或 gamedata 拉取目标玩家群体的付费分布，确定每档付费门槛对应的人群覆盖率。

### Step 3：出大纲对齐

输出档位结构表（档位/积分/累计付费/覆盖人群/ROI目标），用户确认后才进入选道具。

### Step 4：道具选型与数量计算

**价值公式**：
```
单价($) = 100 / 100$价值量
道具价值($) = 数量 × 单价
```

**选型流程**：
1. 确认 SCHEMA，过滤可用道具
2. 确定成长道具线（贯穿骨架，稀缺度递进）和主题道具线（面值递进）
3. 从低档到高档依次填充，每填一个道具检查递进规则
4. 用非主题道具（资源/电池）调节 ROI 到目标区间

### Step 5：ROI 校验

逐档计算 ROI，标注达标状态。不达标的调整道具数量或替换道具。

### Step 6：配置输出

Excel / Google Sheet / 2112 JSON。

## ROI 基准

| 类型 | ROI 范围 | 说明 |
|------|----------|------|
| 礼包（直购） | 1.5 ~ 2.5x | 前期偏高吸引首充 |
| 周卡（登录型） | 5 ~ 10x | 长线留存导向 |
| 周卡（任务型） | 5 ~ 8.8x | 活跃+付费双驱动 |
| 商店（兑换） | 溢价 2x | 兑换代币体系 |
| 排行/任务免费奖励 | 无 ROI 概念 | 按总预算控制 |
| 积分消耗活动 | 15% ~ 20% | 逐档校验 |

## 积分消耗活动的标准档位结构

经验证的通用模板（档数、门槛、具体道具均可根据活动调整）：

```
低档（免费）    ：基础填充道具
低档（微付费）  ：主题小面值道具 + 填充
中档（小R）     ：主题中面值道具 + 填充
中档（中R）     ：当前阶段可用的低稀缺度成长道具 + 主题中面值道具
中高档（中R+）  ：中稀缺度成长道具 + 主题中面值道具
核心转化档      ：中稀缺度成长道具 + 非主题填充 + 核心奖励（钥匙等）
高档（大R）     ：高稀缺度成长道具 + 高价值通用道具 + 主题大面值道具
顶档（超R）     ：高稀缺度成长道具 + 高稀缺度升阶道具 + 主题大面值道具 + 填充
```

**关键规则**：
- 成长道具线（碎片/芯片/图纸等）作为贯穿所有档位的递进骨架，稀缺度逐档递增
- 主题道具线按每日任务主题差异化，面值逐档递增或持平
- 核心转化档必须延续成长道具线，不能中断；预算不够放主题道具时用非主题填充
- 具体用哪条成长线取决于活动所在 SCHEMA：前期用英雄碎片线，中期可加装备/军备线，后期可加机甲/收藏品线
