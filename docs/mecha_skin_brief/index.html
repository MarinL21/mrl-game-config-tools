一、需求概要一套皮肤 4 个等级，逐级加料，同一本体不换模型骨架

等级功能说明视觉增量（相对上一级）动态
LV1 素装皮肤入门形态，玩家首次获得换涂装：钛灰机体 + 细熔橙轮廓嵌线；土气部件全换成科技构件无
LV2 蓄能第二档，能量开始上线加胸口熔炉核心 + 大面积熔岩透光块 + 熔岩裂纹走线 + 背部短散热鳍片核心呼吸、熔岩流动
LV3 拓展第三档，外挂构件上身加大型悬浮装甲环（环绕肩／臂）+ 鳍片加高加密 + 胸腔露熔岩内腔悬浮环自转、导管流光
LV4 特效满级形态，付费点主视觉构件不再增加，全部资源给特效熔橙能量飘带 + 关节喷射粒子 + 周身上扬光点
分级思路：LV1→LV3 只加"看得见的硬件"（涂装 → 熔炉核心与熔岩透光 → 大型悬浮环），LV4 不再加硬件、全部堆特效。每一级都有明确可辨的增量，LV4 的飘带是唯一且最强的记忆点。

LV1 · 素装模块名：金刚机甲皮肤-赛博-LV1
ember_lv1/…527_1
1.赛博朋克风格的机甲皮肤，钛灰／深灰金属机体，哑光带细微磨砂质感，皮肤品质对标猎豹（星间猎手）。
2.严格保留金刚本体的体型比例、驼背四足前倾姿态、猩猩面部识别度——只换涂装和外挂构件，不改模型骨架与动作。
3.原本朴素的部件全部替换成科技构件：布面补丁 → 平整装甲板；粗螺栓铁片 → 隐藏式卡扣；红色炸药管 → 能量导管；圆顶肩甲 → 带切面的棱形肩甲（装甲分块要利落，有明显的切面转折）。
4.霓虹嵌线只走轮廓：沿装甲板边缘走细的熔岩橙发光线，线宽细、不发散，胸腹和四肢各 1-2 条即可。
5.眼睛：青蓝色细长发光眼缝，清亮通透、边缘锐利（就是金刚原立绘那个眼睛效果，见参考图 1）。
动态：无。
注意：LV1 是素装，霓虹只走轮廓线，不要熔炉核心、不要熔岩透光块、不要悬浮件和鳍片，给后面三级留出增量空间。
LV2 · 蓄能模块名：金刚机甲皮肤-赛博-LV2
ember_lv2/…530_0
1.在 LV1 基础上，胸口中央加一枚圆形熔橙发光熔炉核心（半透明球罩，能看到内部翻滚的光芯）。
2.躯干与四肢的嵌线从"轮廓线"延伸成"熔岩裂纹"走线，像装甲下面有岩浆在流。
3.拳部护板、腿甲、脚背加大面积熔岩透光窗（透明护板里是橙色流动的熔岩质感），是这一级最抓眼的点。
4.背部加一排短的棱形散热鳍片（贴着背甲、高度低，片间透橙光）。
5.整体亮度比 LV1 明显上一档，但机体主色仍是钛灰。
动态：胸口熔炉核心呼吸式明暗（约 2 秒一个循环），熔岩裂纹与透光窗跟着核心一起明暗，透光窗里的熔岩缓慢流动。
注意：核心不要做太大，别抢猩猩脸的视觉重心；鳍片这一级只做短的、贴背的，给 LV3 留出"加高加密"的空间；这一级还不要悬浮环。
LV3 · 拓展模块名：金刚机甲皮肤-赛博-LV3
ember_lv3/…533_1
1.在 LV2 基础上加最重的外挂构件：肩部与双臂各加一个大型悬浮装甲环（直径明显，环体金属带暖金发光内圈，浮在装甲外侧不与身体接触）——这是 LV3 的第一眼卖点。
2.背部散热鳍片加高、加密（从 LV2 的贴背短片变成竖立长片），强化驼背轮廓。
3.胸腔装甲打开露出熔岩内腔（能看到里面的熔炉结构），核心保留。
4.颈后到背部加外露能量导管，导管里有橙色流光；霓虹嵌线走满全身，包括手背、脚背、臀部装甲。
动态：1.悬浮装甲环缓慢自转（可正反交替）。2.能量导管与胸腔熔岩循环流动。3.核心呼吸继续。
注意：悬浮环要做大、要能一眼看出比 LV2 多东西，但别挡住头部和拳部轮廓；鳍片高度别超过头顶太多。
LV4 · 特效（满级 · 付费点主视觉）模块名：金刚机甲皮肤-赛博-LV4
ember/…226_1
1.硬件构件与 LV3 一致，不再新增部件，全部资源给特效。
2.机体霓虹亮度整体再提升一档，嵌线由"发光线"变成"高亮流光线"，有流动方向。
3.眼睛发光增强，但形状仍是细长青蓝眼缝，不要变成大光斑。
动态（核心）： 
1.双肩与背部拖出 3-4 条半透明能量飘带，长度约体长的 1.5 倍，末端拉丝散开成细丝，颜色熔橙→金黄渐变，带流光，向后飘动并循环播放（飘带是本级最强记忆点，要够长够飘）。
2.肘、膝、踝关节向外喷射橙色粒子流与火星（细小颗粒，向后上方飞散后消失）。
3.周身有向上飞扬的细小光点，缓慢上升淡出。
4.胸口熔炉核心呼吸 + 嵌线流光继续。
注意： 
1.体型必须和 LV1-3 完全一致的厚重驼背四足比例——概念图这张为了飘带把身体画瘦了、接近人形站立，只取它的特效，不取体型。
2.不要背部羽翼、不要光翼——明确不做翅膀形态（猎豹皮肤已用过，会撞识别）。
3.飘带要虚幻半透明、像能量流，不要做成实体布料或绸带。
4.与战斗特效做区分：飘带和粒子不要遮挡本体轮廓，整体亮度别高到影响战场辨识。
5.参考图 4 是灵感来源（长飘带 + 关节喷射 + 头部粒子），取它的"飘带质感和飘动方式"，不要取它的角色造型。

四、通用规格与避坑四级通用，落每一稿都要过一遍

  • 保住识别度：猩猩脸型、驼背四足姿态、厚重体型三件事不能动。AI 概念图里出现过"改成钢铁侠面罩""体型改瘦成人形站立"两种跑偏，都不要。
  • 眼睛：青蓝细长发光眼缝，不是激光射线、不是大光晕、不是纯白爆闪。四级、全配色统一青蓝，不跟随机体配色换色——暖橙机体配冷青眼是刻意的冷暖对比。
  • 霓虹节制：嵌线按等级递进铺（轮廓线 → 熔岩裂纹 → 走满全身），不要一上来满身乱铺；避免彩虹渐变条（会花）。
  • 材质区分：机体哑光金属、霓虹发光、熔岩透光件半透明，三种材质层次要拉开，别做成通体反光塑料感。
  • 四级一致性：四稿必须同一视角、同一姿态、同一光照、同一体型，方便玩家在商店里逐级对比。
  • 底色：立绘交付走纯色实底或透明底，不要灰白棋盘格假透明。
