01一句话定位与立项背景

在 P2 节日活动体系内，做一个「卡牌英雄 + 装备养成」的零决策子玩法： 英雄与装备全部以卡牌呈现（一套获取 / 强化 / 碎片合成的统一卡牌经济），自由编成五人小队（T / N / DPS 任意组合），装备卡镶上去、强化喂上去把战力堆起来；对战是全自动的 5v5 站桩互殴、纯战力比拼 —— 每个节日常驻开启、轮换英雄与卡池，逐步替换衰减的纯抽 GACHA 坑位，并成为节日外显的新投放主阵地；关卡掉落双轨（玩法道具 + P2 主游戏道具），子玩法与 SLG 主成长息息相关。

版本轨迹：v1.1 炉石式卡组决策→零决策 ｜ v1.2 装备去卡化 + 内嵌抽奖 + 付费点定版 ｜ v1.3 五人小队 ｜ v1.4 编成自由（战斗零操作）｜ v1.5 掉落双轨与主游戏耦合 ｜ v1.6 全卡牌化 ｜ v1.7 分层体验（0 氪可达保证）—— 卡牌只承担「收藏形态 + 视觉资产」职能，玩家全部投入都在养成与收集层。

为什么做（三个被数据验证的判断）

判断数据支撑（均出自本人回归报告）对本案的含义
玩家时间是被验证的富矿 挖孔七期（活动 UI 点击流会话化实测）：全服累计投入 9,179 小时（保守口径，宽口径 17,880 小时）； 人均 38 分钟 / P90 达 100 分钟，3,157 人（21.6%）投入超 1 小时； 238 万次挖掘动作、人均活跃 3.46/7 天、38.3% ≥5 天、87% 使用挂机 P2 玩家有大量「游戏内可支配时间」，活动玩法是时间的容器，付费是时间投入的副产品
纯抽 GACHA 形式在衰减 弹珠 GACHA（纯抽）四个投放期：周年庆 $393,020 → 万圣 $155,816 → 圣诞 $144,974 → 科技 $126,371， 连降三期、峰值回撤 -68% 衰减的不是付费意愿，是「纯抽」形式的新鲜感 —— 需要一个玩法型形态来接替坑位
P2 玩家为外显与数值成长付费 头像框礼包买家渗透 96.3%；挖孔图鉴收集 71.9 万件宝物、图鉴断崖处付费中位数 $2.86 → $1,058； 挖孔 ARPPU +151% 全部来自「推进路径上的付费点」 收集 + 战力成长是 SLG 玩家最熟悉的两种付费动机 —— 本案把两者做成同一条线

为什么是「卡牌形态 + 零决策」

  • 战斗零操作 = 零门槛：SLG 玩家的日常就是比战力 —— 战斗全自动、编队有一键推荐（想动脑的有编成空间，不想动的不强迫）， 堆战力、点开打、看结果，和主玩法的心智完全同构；碎片时间一场 15 秒；
  • 收集即本体：英雄卡、装备卡与节日外显全部进图鉴，收集直接加战力（见 §07）——玩家只需要理解「卡」一个概念，获取 / 强化 / 合成 / 收集全线统一；挖孔归因四要素中最强的「图鉴收集」在全卡牌形态下天然成立，且有了数值意义；
  • 美术成本极低：卡面 = 单张静态插画，AI 生图管线（60 张/批）为此而生；
  • 程序成本更低（较 v1.0 再砍一截）：卡牌规则引擎、手牌/费用/关键词系统全部不要了 —— 只剩战力计算 + 互殴演出 + 养成框架，零战斗动画、零实时同步；
  • 付费上限更高：静态卡免费获取养大盘，动态卡 / 签名卡直售（炉石黄金卡、Marvel Snap 变体卡先例） + 装备强化材料这条经典 ARPPU 线（挖孔已验证）。
定位一句话：不是卡牌对战游戏，是「披着收藏卡外壳的战力养成闯关」—— 玩家时间从这里进来，外显与付费从这里出去。

02玩法总览：核心循环

一场 10 秒的自动互殴，套在「闯关 → 掉装备 → 穿戴强化 → 战力提升 → 更深关卡」的循环里

▲ 图 2-1 核心循环（自绘示意）。黄色为挂机支线（四要素之「挂机留存」），红色节点为坑深所在（四要素之「循环关持续领奖」）。

一局怎么玩（15 秒版本）

  • 首次进入活动即送基础五人队（1T + 1N + 3DPS 每职业保底，零门槛直接能打）；
  • 点关卡 → 5v5 站桩互殴全自动：T 顶在最前扛伤、奶妈自动奶血最低的、三个 DPS 集火对面前排 —— 卡牌冲撞、伤害与治疗飘字、血条起落，约 15 秒出结果；
  • 胜负基本由队伍总战力决定（战力差大时直接"碾压"快速演出）—— 战斗内没有手牌、没有操作；玩家唯一的表达是赛前怎么组队；
  • 赢 → 掉装备卡 / 碎片 / 材料 / 抽奖币 + P2 主游戏道具（双轨掉落）；输 → 明确提示差多少战力 + 三个提升入口（换更强英雄 / 强化卡牌 / 收集图鉴）。

03英雄系统：获取与等级（唯一的卡）

英雄卡：小队的核心资产 —— T / N / DPS 三职能 · 五人自由编成；首入即送 / 玩出来 / 抽出来三条通道；等级驱动卡面进阶

职业与编成：三职能，五个位，怎么组是玩家的自由

职能站位（系统自动）写死的行为规则数值偏向
坦克 T自动排在最前用身体挡枪 —— 敌方攻击永远打「存活的最前位」，T 就是队伍的墙生命 / 防御成长高
治疗 N自动排在最后每回合治疗己方血量比例最低者，不参与输出治疗力成长高
输出 DPS自动排在中间攻击敌方「存活的最前位」—— 先啃掉对面前排，经典集火攻击成长高
  • 自由编成：5 个上阵位，任意职业组合 —— 5 DPS 速攻、2T2N1D 龟壳、标准 1T1N3DPS 都随玩家；站位由系统按 T → DPS → N 自动排序（同职能按战力排），战斗内依然零操作；
  • 一键推荐：不想动脑的玩家点一下 —— 系统按拥有英雄自动组推荐队（默认标准构成 / 战力最优），编队决策可选而不强迫；
  • 策略自然涌现（不需要克制表）：多 T = 更耐久、多 N = 更能拖、多 DPS = 抢先手清场 —— 三种倾向全部由生命 / 治疗 / 攻击三条属性自然导出，数值上没有任何新增复杂度。

获取：三条通道（结构定死，逐期只换英雄）

通道获取方式设计意图

② 玩出来（确定性） 章节首通解锁第二名英雄；爬塔里程碑与节日活跃任务稳定产英雄碎片，攒够直接兑换 零氪与中小 R 的确定性奔头 —— 肝有明确回报，活跃被持续拉住
③ 抽出来（内嵌英雄抽奖） 抽奖币抽卡，统一奖池 = 本期限定英雄 / 装备卡 / 卡牌碎片 / 强化材料 / 外显；N 抽保底必得本期限定英雄（概率与保底公示）；抽不到英雄也有装备卡进账，重复卡自动转碎片 —— 双重零废抽 惊喜感 + 付费加速；限定英雄的稀缺窗口制造本期目标

内嵌抽奖为什么成立（而不是又一个会衰减的纯抽 GACHA）

  • 抽奖有语境：抽出来的英雄马上上阵、进图鉴、加战力 ——「为了用而抽」和「为了抽而抽」的付费质量完全不同（§01 时长×付费阶梯的另一面）；
  • 免费量守恒：抽奖币在闯关与活跃中稳定掉落但每日/每期封顶（挖孔「免费供给设上限」原则），付费买的是加速与保底冲刺，不破坏获取公平；
  • 程序近零新增：抽奖 / 保底 / 概率公示直接复用 P2 现成 GACHA 组件（熟基建），策划只配奖池表。

等级：英雄的区分度与视觉成长

机制设计

04卡牌与装备：一套卡牌经济

英雄卡与装备卡同框同规则 —— 统一抽奖 / 统一强化 / 统一碎片合成；活动概念收敛为「卡 + 碎片 + 材料」

两类卡，一套规则

类型作用获取强化碎片
英雄卡上阵作战（T / N / DPS 职能），等级驱动卡面框体进阶首入即送 / 玩出来 / 统一抽奖喂强化材料升级 → 属性 + 换框重复转碎片 → 合成新英雄 / 突破段位
装备卡镶嵌英雄卡槽位（倾向 4~6 槽）加属性 —— 五人上阵 = 养成面 ×5关卡掉落（主渠道，深关掉好卡）/ 统一抽奖 / 碎片合成同一套喂养交互 → 属性 + 卡面特效升阶重复转碎片 → 合成 / 升阶

统一三机制（活动清晰的来源）

① 统一抽奖：一个池同时产出英雄卡与装备卡 —— 英雄是稀有大奖、装备是常规产出， 抽不到英雄也有装备卡进账（零废抽）；N 抽保底本期限定英雄，概率与保底公示；
② 统一强化：英雄卡与装备卡用同一套喂养交互、同一类强化材料（配比数值另定）—— 玩家学一次操作，全程通用；
③ 统一碎片合成：任何重复卡自动转为该卡碎片；碎片攒够可合成该卡（没抽到也能肝出来的确定性闭环）， 已拥有的卡碎片用于突破 / 升阶 —— 皇室战争、咸鱼之王验证过的经典卡牌经济。

概念收敛：活动内玩家要理解的资源只有三种 ——「卡（英雄/装备）+ 碎片 + 强化材料」， 外加行动力与抽奖币两个入口货币；对比传统「英雄+装备+材料+图纸+代币…」的多概念活动，认知负担减半，活动更清晰。

05对战：5v5 站桩互殴，零决策

经典站桩自动战 —— 战斗不是玩法，是「战力的验收仪式」；开发简单 · 理解简单 · 数值简单

战斗规则说明书（可实现级 —— 数值系数另出，规则一次定死）

规则项定义
编成玩家自由选 5 名英雄上阵（职业组合不限）；敌方编成由关卡表配置（普通关 3~5 只、精英满编、BOSS = BOSS + 护卫）
站位双方各一列：按 T → DPS → N 自动排序，同职能按战力降序 —— 无手动站位
行动顺序双方交替、各自从前往后轮流出手（我 1 → 敌 1 → 我 2 → 敌 2 …），阵亡位跳过 —— 完全确定，无速度属性、无随机
目标规则（全部两条）攻击类（T / DPS / 怪）：打对方存活的最前位；治疗类（N）：奶己方血量比例最低的存活单位
结算公式形态伤害 = 攻击 × 技能系数 − 防御（保底最低伤害）；治疗 = 治疗力 × 系数；无暴击 / 无闪避 / 无属性克制（首期）
死亡与补位血量 ≤ 0 置灰退场，后位自动前移补位
胜负判定一方全灭即负；达回合上限（防拖局）按双方剩余血量百分比判定
战力公式形态单位战力 = 攻击 / 生命 / 防御 / 治疗力的线性加权；队伍战力 = 5 单位之和 + 图鉴全局加成 —— 战前对比展示的就是这个数
碾压 / 失败战力差超阈值 → 快进一击全灭 +「碾压」特写；失败 → 显示战力差 + 三个变强入口（换人 / 强化 / 图鉴）
为什么这套对战「经典」且三处简单：
① 开发简单：一个顺序行动循环 + 两条目标规则（攻击打最前 / 治疗奶最低）= 全部战斗逻辑；无寻路、无技能树、无行为树，敌我共用同一套结算与演出 —— 程序量是「带演出的数值比大小」；
② 理解简单：「T 扛、奶奶、DPS 打」—— 三句话教学完毕；编队自由但有一键推荐，想动脑有空间、不想动零门槛；
③ 数值简单：只有攻击 / 生命 / 防御 / 治疗力四条属性 + 线性公式；流派差异（耐久 / 续航 / 速攻）从属性自然涌现，不需要克制表 —— 平衡只调成长曲线，蒙卡跑通过率定档。

PVE 优先、PVP 零成本：首期纯 PVE（敌方编成全配置表驱动）。 二期若加 PVP，就是战力擂台：抓取对方五人队数据打一场自动互殴回放 —— 依然零决策、零实时同步、零平衡压力（比的就是谁养得好，SLG 玩家最服这个）。

07图鉴与节日外显（收集加战力）

收集不只是情怀 —— 图鉴点亮直接加全局战力，中小 R 的收集有了确定性的数值回报

  • 收集加战力：英雄/装备图鉴每点亮、养成到位若干张 → 全局战力永久加成；集齐节点（25 / 50 / 80 / 100%）发大奖， 终点奖励为本册限定外显 —— 缺口可视化（灰色剪影 + 「距下一档还差 N 张」）是收集付费的核心触发器；
  • 外显双通道：节日外显从「货架直售」升级为「玩出来 + 买出来」——获得有过程、稀缺有叙事； P2 现有节日外显产线（皮肤/头像框/表情）的产物全部可入册复用；
  • 与挖孔图鉴断崖的衔接：挖孔数据证明图鉴后段追求属于鲸鱼（25→35 种处付费中位数 $2.86 → $1,058）—— 本作图鉴分册 + 节点化：中小 R 每册前段有确定性奖励与战力回报，鲸鱼在「全收集 + 动态卡」处有无上限追求。

14风险与对策

风险对策
玩法太轻、易腻节日短周期（7~14 天）天然匹配轻玩法 —— 玩的是「这期收不收得齐、爬多高」，不是玩法新鲜感；收集/爬塔/外显三条目标线轮着给钩子；每节日新英雄新卡池自带新鲜感
零决策被评「没深度」这是定位不是缺陷：对标咸鱼之王 / AFK 式「卡牌小队 + 数值养成」的成熟品类；战斗零操作、编队自由 + 一键推荐（决策可选不强迫）；深度在编成流派、养成规划与收集执念，不在操作 —— 与 SLG 主玩法用户画像同构（挖孔 79.3% 零付费重度参与者就是这批人）
养成曲线数值风险战力/掉落/强化曲线用蒙卡模拟工具（挖孔模拟器同款方法论）批量跑推进节奏定档；数值框架单独评审
美术量超预期卡面 AI 批产已实测（60 张/批）；框体程序拼装避免逐卡排版；动态卡按人气排产（先上主战英雄）
与现有 GACHA 收入互食本案定位就是「替换衰减坑位」而非叠加：排期上错峰接替表现最弱的纯抽位，用回归数据决定替换节奏
程序排期竞争零规则引擎 / 零动画 / 零实时同步 / 全表驱动 —— 程序量已压到「带演出的数值比大小」级别；一次开发多年复用，ROI 论证见 §01
